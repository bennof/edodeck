Schrittweise Liste

Jeder Punkt erscheint einzeln bei „Weiter“ — erst wenn alle sichtbar sind, springt Weiter zur nächsten Folie.

  • Erster Gedanke
  • Darauf aufbauend der zweite
  • Und die Schlussfolgerung

Aufdeck-Reihenfolge (data-order)

Reihenfolge im Markup: 3 → 1 → 2. Reihenfolge beim Aufdecken: data-order 0 → 1 → 2.

  • Steht im Markup an dritter Stelle — data-order="2", erscheint zuletzt
  • Steht im Markup an erster Stelle — data-order="0", erscheint zuerst
  • Steht im Markup an zweiter Stelle — data-order="1", erscheint als zweites

Fragment-Varianten

Jeder Punkt nutzt eine andere Klasse aus reveal.css — der Inhalt selbst braucht kein JavaScript.

  • fade-up
  • fade-left
  • grow
  • fade-out — startet sichtbar, verschwindet
  • strike — durchgestrichen beim Aufdecken
  • highlight-accent
  • highlight-success
  • highlight-error

Aktueller Punkt

Ältere Punkte dimmen ab, sobald ein neuer aufgedeckt wird — nur der aktuelle bleibt voll sichtbar.

  • Erster Schritt
  • Zweiter Schritt
  • Dritter Schritt
  • Vierter Schritt

Hintergrundbild

class="bg-cover bg-dim" + style="--bg-src:url('...')". Alternativ bg-contain oder bg-stretch.
