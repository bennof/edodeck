Reveal order (data-order)

Order in the markup: 3 → 1 → 2. Order when revealing: data-order 0 → 1 → 2.

  • Third in the markup — data-order="2", appears last
  • First in the markup — data-order="0", appears first
  • Second in the markup — data-order="1", appears second

Fragment variants

Each point uses a different class from reveal.css — the content itself needs no JavaScript.

  • fade-up
  • fade-left
  • grow
  • fade-out — starts visible, disappears
  • strike — struck through when revealed
  • highlight-accent
  • highlight-success
  • highlight-error
